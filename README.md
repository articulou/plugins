# Plugins do Articulou

Catálogo (marketplace) dos plugins do Articulou para o Claude: um plugin por organização, cada um com o conector da sua
instância e a skill `eleicoes-sp`, que faz o Claude usar o Articulou sozinho em qualquer pergunta eleitoral sobre São Paulo.

## Instalar

- **claude.ai e Claude Desktop:** Customize → Plugins → Add → Add marketplace → `https://github.com/articulou/plugins`;
  instale o plugin da sua organização e, na aba Connectors dele, clique em Conectar e entre com o e-mail convidado.
- **Claude Code:** `claude plugin marketplace add articulou/plugins` e `claude plugin install articulou-uniao@articulou`.

O catálogo é público e não tem dado nenhum: o acesso aos números é pelo login na instância da organização.
